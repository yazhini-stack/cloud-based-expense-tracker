# ☁️ Cloud-Based Expense Tracker & Analyzer

A simple cloud-based application for analyzing personal expense data using **Google Colab, Python, Pandas, and Matplotlib**.

## 📌 Project Overview

This project analyzes expense data and provides useful insights into spending patterns.

## 🚀 Features

- Total expenditure calculation
- Transaction count
- Average expense
- Highest individual expense
- Category-wise spending analysis
- Payment-mode analysis
- Monthly expense analysis
- Expense visualizations
- Automatic spending insights
- Custom CSV upload
- Processed CSV download

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

## ☁️ Cloud Component

Google Colab is used as the cloud computing environment. Users can upload their expense dataset and perform data processing and analysis in the cloud without requiring local Python installation.

## ▶️ How to Run

1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells from top to bottom.
3. Use the sample dataset or upload your own CSV.
4. View the generated analysis and visualizations.
5. Download the processed dataset if required.

## 📄 Required CSV Columns

Your custom CSV should contain:

- `Date`
- `Category`
- `Description`
- `Amount`
- `Payment_Mode`

## 🎯 Purpose

The project demonstrates how cloud-based computing can be used for simple financial data analysis and visualization.
